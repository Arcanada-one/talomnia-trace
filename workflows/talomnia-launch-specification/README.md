# Workflow 0 — Talomnia Launch Specification

**Status: trace being assembled.** This directory is the reserved, stable location
for the first published workflow: how the Talomnia launch specification came to be —
client discovery → discussion → requirements → contradictions/TBD → technical
assignment → validation → accepted specification → input to orchestration.

The published evidence is the **process**, not a specification file: including the
contradictions and gaps found on the way and how each was resolved or escalated.
A polished version with the traces of real work edited out would not meet the
requirement this workflow exists to demonstrate.

| Path | Will contain |
|---|---|
| `tasks/` | Anonymized orchestrator task briefs of the specification workflow. |
| `artifacts/` | Sanitized projection of the accepted specification and intermediate artifacts. |
| `correspondence/` | Sanitized discovery/validation correspondence. |

Site page (once live): `talomnia.com/workflows/talomnia-launch-specification`.
